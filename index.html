Savaitės YouTube vaizdo įrašas

1. Atsisiųsti atnaujintą index.html failą (su visais jūsų pakeitimais)

Visi renginiai, kavinės, koncertų įžvalgos ir tekstai, kuriuos čia įvedėte, bus įrašyti tiesiai į atsisiunčiamą index.html failą. Tada jį galėsite įkelti į GitHub saugyklą (rimantas-creator/renginiai-test) arba į iv.lt serverį.

2. JSON atsarginė kopija ir atkūrimas

Išsisaugokite tik duomenų kopiją (JSON) arba įkelkite anksčiau išsaugotą kopiją.

Trumpa atmintinė keliant į GitHub ir iv.lt:
  • Failas visada turi vadintis tiksliai index.html (mažosiomis raidėmis, su vienu tašku).
  • Įkėlus į GitHub, puslapis atsinaujina per 1–2 minutes (naršyklėje paspauskite Ctrl + F5).
  • Kai perkelsite į iv.lt hostingą, tiesiog įkelkite šį patį index.html į public_html katalogą.
